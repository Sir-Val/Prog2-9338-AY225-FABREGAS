Programming 2: 2-Week Game Sprint

Original Mini-Game Logic & Codebase Implementation

Project Overview

This is a fast-tracked, 14-day development cycle for Programming 2 students. Working in pairs, you are required to build a functional mini-game from scratch. The focus is on applying core programming concepts (Logic, OOP, and Data Structures) within a collaborative GitHub environment.

Objective: Develop a complete game codebase hosted on GitHub that demonstrates technical proficiency and team synchronization.

Project Requirements

1. Development Platform

Groups must choose only one of the following languages for their game development:

JAVA (Swing/AWT or FX)
JAVASCRIPT (Canvas or DOM-based)

2. The Game Codebase

  • Original Logic: Must include a Main Menu, Core Gameplay Loop, and a Game Over/Score state.
  • Version Control: The project must be hosted in a public GitHub Repository.
  • Documentation: A comprehensive README.md featuring:
    • Game Title & Description
    • Setup Instructions (How to run the code)
    • List of Controls
    • Screenshots of the final build

3. GitHub Collaboration (Strictly Monitored)

To ensure equal contribution and collaborative learning:

  • Commit Requirement: Each member must have at least 15 meaningful commits.
  • Commits such as "update", "fix", or "test" without context are discouraged. Use descriptive messages.
  • Both members must contribute to the logic/coding (not just documentation).

Project Schedule (2-Week Sprint)

Day 1-2: Pair formation, language selection (Java/JS), and Repository setup.
Day 3-7: Development of core classes, game physics, and input handling.
Day 8-11: Implementation of UI (Menus/Scoring) and asset integration.
Day 12-13: Code Refactoring, bug squashing, and reaching the 15-commit minimum.
Day 14: Final Code Defense and Live Demo.
